# vsevserios.ru

## Оплата (ЮKassa)

Ключи в коде не хранятся — задайте в `.env`:

```
YOOKASSA_SHOP_ID=...
YOOKASSA_API_KEY=...
# при включённых чеках 54-ФЗ:
YOOKASSA_SEND_RECEIPT=1
YOOKASSA_VAT_CODE=1
YOOKASSA_TAX_SYSTEM_CODE=
```

В личном кабинете ЮKassa → HTTP-уведомления укажите URL
`https://vsevseryoz.ru/accounts/payment/yookassa/webhook/` (события `payment.succeeded`, `payment.canceled`).
Уведомления не считаются доверенными: статус и сумма платежа перепроверяются запросом к API ЮKassa.

Правила доступа: первый месяц — подробный анализ совместимости бесплатно; затем виден только общий процент,
подробный анализ и графики — по подписке 500 ₽/мес (кошелёк). Анкеты, присланные администратором по заказу подбора,
открыты без подписки. Подбор администратором (500 / 2000 / 10000 ₽) оплачивается за каждую взаимную симпатию;
для запуска заказа на балансе должна быть сумма не меньше цены тарифа. Администраторам (`is_staff`/`is_superuser`)
оплата недоступна.
